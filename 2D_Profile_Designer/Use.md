# 2D Profile Designer - User Guide

> **Kynetic Metal Works** | Custom Metal Profile Design Tool




**FOR INTERNAL ODOO USER**


## After Email is sent/recieved
1- Go to Odoo and check to see if the product type already exists
    - If it does, create a new manufacturing order with the correct attributes. 
    - If some of the attributes do not exist but the product is correct, create new attributes. 
2- If it does not, go to inventory -> products -> products
3- Click "New" in the top left and fill in the given infomration from the email
    **NOTES**
    - Make sure to add the image of the profile
    - Make sure to select the correct company (Probably Kynetic)
    - Go to the Sales tab next to Attributes & Variants and selected the "Published" checkbox. 
    - If a pricelist is applicable or a customer filter, add that. 
4- Go to Manufacturing -> Operations -> Manufacturing Orders. Create the order with the correct product and quantities. 
    **NOTES**
    - attach the right company to the Order. 
    - Put it in the correct spot in the manufacturing process.
